Privacy policy

AutoDL Drive Backup is a personal rclone configuration for transferring selected files between the owner's AutoDL server and their Google Drive account.

Google Drive data

The app requests Google Drive's drive.file permission. It can create, read, update and delete files created by the app or files explicitly selected for it. Data is used only to perform the backup and restore operations initiated by the owner.

Storage and transfer

Source files remain on the owner's server; copied files are stored in the owner's Google Drive. Credentials are stored in the owner's server configuration. Requests to Google use HTTPS and currently pass through the owner's configured AWS proxy; the involved infrastructure providers may process connection metadata.

Sharing and analytics

The app does not sell Google user data or use it for advertising. Its use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements. This informational website uses no analytics or advertising scripts. The service providers needed to operate the server, proxy, and Google Drive have their own data practices.

Control and deletion

The owner can revoke the app's access from their Google Account security settings. The owner controls deletion of the app's server configuration and the backup files in Google Drive. Revoking access does not itself delete stored backups.
