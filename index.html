AutoDL Drive Backup

A personal backup configuration using rclone to copy selected files from the owner's AutoDL server to their own Google Drive, and to read them back when needed.

The Google Drive permission is limited to files created by this app or explicitly selected for it. The app can create, read, update and delete those files. The owner controls the source files, the server, the Google account and the backup destination.

This is a personal tool, not a public file-hosting or file-sharing service. It does not provide access to the owner's files to visitors to this website.
